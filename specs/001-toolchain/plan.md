# Implementation Plan: Developer Toolchain

**Branch**: `001-toolchain` | **Date**: 2026-09-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-toolchain/spec.md`

## Summary

Establish a single, committed, offline-capable developer toolchain: Biome v2 replaces Prettier
for both formatting and static analysis (one dependency, one config), the npm script surface
gains `format` / `check` / `check:fix` / `verify` on top of the existing `start` / `test` /
`build`, and TypeScript project configuration is aligned so the typecheck gate and the unit-test
runner agree. `verify` runs every gate (formatting check, lint, typecheck, unit tests, build)
and fails on any of them. The toolchain configuration is committed, so results are reproducible
across contributors — satisfying SC-001…SC-004 and the Constitution's local-gates mandate.

## Technical Context

**Language/Version**: TypeScript `~6.0.2`, Angular `22.1.x` (existing), Node 24 (via fnm) + `pnpm@11.20.0`

**Primary Dependencies**: `@biomejs/biome` `2.5.12` (exact-pinned, devDependency; replaces
`prettier`). No ESLint is added — Biome covers lint + format + import organization.

**Storage**: N/A — pure developer toolchain; no runtime persistence involved.

**Testing**: Unit: existing Vitest 4 via `@angular/build:unit-test`. Static: `biome ci .`.
Typecheck: the existing `@angular/build` production build (AOT + `tsc`) acts as the gate;
`verify` composes them.

**Target Platform**: Developer machines — Windows 11 + PowerShell is the primary environment;
scripts MUST avoid POSIX-only constructs so they also run on macOS/Linux shells.

**Project Type**: Single-project Angular SPA (frontend web application) + developer toolchain.

**Performance Goals**: `check` completes in under 60 seconds on the current repository size
(SC-002; Biome is a fast Rust binary, comfortably within reach).

**Constraints**: Offline-capable check commands (no remote rule fetching); exact-pin Biome so
formatting is deterministic across machines; only one source of truth for lint+format rules.

**Scale/Scope**: Small team (foundation slice). The toolchain is reused by every later feature,
so it must be committed and documented before feature code accrues.

model (root/app/spec) but align their strict settings under one shared root so the typecheck
gate and the Vitest runner agree.
